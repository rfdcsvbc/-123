# 回 · 手势八卦

[中文](README.md) · [English](README.en.md) · [在线体验](https://huzoukai.github.io/hui-gesture-bagua/)

一个通过单手手势、鼠标和键盘控制的生成式八卦动态体验。

**作者：科技回锅肉**

> 本仓库是 HUI 正式体验的公开视觉演示版，保留同一套十四层八卦视觉结构与手势动效，但不包含商业产品中的起卦、AI、支付、邮箱或服务器功能。公开源代码仅允许个人学习、研究与非商业娱乐使用；未经书面授权，不得用于商业目的。

## 体验

这个项目把手变成界面。使用者不需要控制器，只需要依次完成几个自然动作：

| 动作 | 视觉回应 |
| --- | --- |
| ☝ 伸出食指 | 在指尖位置唤醒阵眼；远近控制亮度 |
| ✊ 握拳 | 从中心逐层展开完整平面阵 |
| 🖐 张开手掌 | 平面结构上下分层，形成三维空间 |
| 🖐 转动掌心 | 控制立体阵的方向和倾角 |
| ↔ 横向挥掌 | 开启或关闭金色旋涡 |
| ✊ 再次握拳 | 从立体状态收回平面 |
| 🤏 拇指与食指捏合 | 聚集灵力，松开释放冲击波与星河粒子 |
| ✌ 比耶 | 在青霄、鎏金、紫微、朱雀四套配色间切换 |
| ☝ 食指停在闪烁光点 | 在“八卦追光”挑战中，保持约半秒点亮目标 |

### 更灵敏的手势识别

识别使用手掌大小归一化的三维距离、PIP/DIP 关节角度、骨链伸直程度和摄像头画幅比例。握拳要求四指全部弯曲；捏合要求拇指、食指接触，并且其余三指中至少两指明确伸直。半捏合、关节退化或不明确的姿势不触发动作，避免把攥拳误当蓄力。

普通动作默认约 65 毫秒确认，握拳至少 120 毫秒、捏合至少 160 毫秒。也可选择“均衡”或“稳健”。蓄力只有在稳定识别到张开手指后才释放，改成握拳或丢手会取消；取消后的握拳不会同时触发收拢阵图，必须重新张掌才能开始下一次捏合。真实摄像头仍可能受遮挡、强逆光和侧掌影响，无法承诺任何情况下零误识别。

支持双手张掌缩放：双掌拉开放大、靠近缩小；双手同时入镜时暂停单手指令，避免缩放中误触蓄力。滑块、加减按钮、滚轮和键盘加减也可以在 45%～180% 之间调节大小，切换平面/立体保持所选倍率。

短暂丢失手部不再清空八卦阵。可以通过“查看手部”显示本地画面、关键点和识别帧率，检查手是否完整进入画面。识别模型和 WASM 随构建一起打包，无需访问外部模型 CDN。

### 新玩法与特效

新增指尖流光、环绕能量轨道、八方光点、蓄力增辉和粒子爆发。“八卦追光”每局随机排列八个目标，用食指、鼠标或触屏指向闪烁光点并保持约 0.55 秒，全部点亮后显示用时并触发庆祝效果。丢手或移出目标会取消当前光点的停留进度。

### 符箓与声音

按 **F** 或点击“符箓模式”弹出黑底金边卦签。默认「雷地豫」照用户提供的科技回锅肉视频 00:32 画面制作：左侧六爻图、竖排卦名、“吉”字、上雷震 / 下地坤、中英文解签、“六爻安静 · 守常则吉”和“再卜一卦 / 收签”按钮。文字用原生中文字体独立排版，不经过 WebGL 辉光，保证清晰。提供乾为天、坤为地两张额外文化卡片；“再卜一卦”在这三张本地卡片间切换，不是完整六十四卦或 AI 解卦。“卦签题字”可自定义最多八字。

捏合蓄力后张掌出签，握拳收签，双掌拉开 / 靠近调整大小。开启摄像头后，食指会显示带进度环的光标：指向按钮停留 0.9 秒即可执行，同一控件只执行一次，移开后才能再次执行。可用手势开关符箓、再卜一卦、收签、切换主题和玩法、重置、调音量和静音。指向下拉选项停留会轮换；指向滑块停留可设置所指位置的数值。左侧“操作栏 ↑ / ↓”支持用手势翻看被折叠的控制栏。手部丢失、姿势不明确、改为双掌或捏合时，停留进度取消。首次仍需点击开启摄像头并授予浏览器权限。

声音默认开启；进入体验时解锁浏览器音频，包含环境音、升维、持续蓄力、冲击波和出符铃音。可以调整音量、静音或点击“试听 ♪”确认音频是否已开启。页面隐藏时暂停音频，离开时关闭音频节点并清理计时器。

卦签为传统文化视觉与本地卡片互动，不包含六爻生成、问题输入、AI 解读、支付或未来预测功能。

## 十四层视觉结构

公开体验由天池太极、先天八卦、洛书九星、二十四天星、地盘正针、穿山七十二龙、人盘中针、透地六十龙、天盘缝针、一百二十分金、六十四卦、二十八星宿、二十四节气与周天刻度共同组成。

所有环带保持统一中心与固定比例。平面状态不再让各层独立缩放；立体状态只沿预设深度展开，从而避免文字漂移、环带松散和层间穿插。移动设备会自动降低纹理分辨率、粒子数量和像素密度，以减少发热与显存压力。

## 手动模式

不启用摄像头也可以完成全部主要动画：

| 操作 | 功能 |
| --- | --- |
| 点击 | 按“阵眼 → 平面 → 立体 → 平面”推进 |
| 移动鼠标 | 控制立体阵方向 |
| 滚轮 | 缩放 |
| **V** | 开关旋涡 |
| **T** | 切换四套主题 |
| **空格（按住 / 松开）** | 蓄力 / 释放冲击波 |
| **G** | 开始或结束八卦追光挑战 |
| **F** | 开关符箓模式 |
| **+ / −** | 放大 / 缩小 |
| **R** | 重置 |
| **M** | 静音 |
| **Esc** | 停止摄像头并切换为手动模式 |

## 为什么制作

八卦在这个项目中不是一个被动观看的装饰图案，而是一套表现变化、关系与位置的动态结构。伸指、握拳、张掌与挥动对应“显现、展开、形成空间、改变方向、回归”的过程。

“回”既是内外嵌套的视觉结构，也是动作发出、视觉回应、注意力重新返回使用者自身的过程。

这是科技回锅肉对传统符号进行的当代数字视觉创作，不是历史罗盘、风水器具或传统仪式的精确复原，也不代表任何文化传统的唯一解释。进一步说明见[文化背景与资料来源](docs/SOURCES.md)。

## 摄像头与隐私

- 摄像头只会在使用者主动点击后开启。
- 视频帧和手部关键点只在浏览器中处理。
- 项目不上传、录制或保存摄像头画面。
- 项目不建立生物识别身份。
- 不使用广告、分析或行为追踪服务。
- 使用者可以随时停止摄像头，或直接选择手动模式。

完整说明见[隐私与摄像头处理](docs/PRIVACY.md)。

## 本地运行

需要 Node.js 20 或更高版本。

~~~bash
npm install
npm run dev
~~~

构建和测试：

~~~bash
npm test
npm run build
~~~

摄像头通常只能在 HTTPS 页面或 localhost 中使用。

### Windows 桌面一键打开

双击桌面的“八卦图手势交互”快捷方式即可自动启动本地页面并用默认浏览器打开，无需手动运行命令或保持终端窗口开启。

`start.ps1` 会在缺少构建或源文件更新时自动构建，优先使用 5188 端口，校验服务身份和项目目录后才复用已有服务；端口被其他程序占用时自动尝试后续端口。页面就绪后才打开浏览器。`scripts/serve.mjs` 只监听本机回环地址，直接提供构建后的页面和本地手势模型。

可运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -NoBrowser` 单独检查启动；最近的启动地址记录在 `launch-state.json`，错误记录在 `server-*.err.log` 或 `build.log`。

`npm run test:launcher` 验证冷启动、端口冲突避让和重复启动。开发服务中的 `/tests/model-smoke.html` 可以在不启用摄像头的情况下自检本地完整模型初始化和空白帧推理；`/tests/interaction-smoke.html` 用合成关节点走真实的手势分类、蓄力路由、双掌缩放、食指停留、菜单翻页、音量和玩法切换。测试入口只在开发构建中启用，正式构建不接收测试消息。真实摄像头的效果还会受光线、遮挡和硬件影响，建议打开手部预览现场调整。
